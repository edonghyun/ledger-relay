Scenariosbreak it on purpose
데모 조작은 demo 프로필에서만 열립니다.
① 정상 결제
Store에서 결제 → 결제 승인됨(구매자 돈이 묶임) → Ship → 결제 완료(가맹점으로 이동).
② TigerBeetle 연결
끊으면 주문은 계속 접수되고 backlog가 쌓입니다. 다시 이으면 한 번씩 비워지고 정합성은 초록 그대로입니다.
③ 잘못된 확정 넣기
예약보다 앞 순번의 확정 → 그 주문만 멈추고 나머지는 흐릅니다. Operator 탭에서 포기하면 주문은 취소됨으로 끝납니다.
④ 더블 클릭
같은 Idempotency-Key로 결제 요청 둘을 동시에 보냅니다. 주문 하나, 예약 하나여야 합니다.
⑤ 출고 전 취소
결제 승인된 주문의 Cancel → 예약 해제, 묶였던 돈이 풀립니다.
주문 50건 몰아넣기
여러 구매자의 주문을 각기 다른 키로 한꺼번에 넣습니다. 워커 둘이 같은 명령을 함께 집지 않고 나눠 처리합니다(Store의 인스턴스별 보낸 수).
